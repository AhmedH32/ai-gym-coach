# ID: PROG_OVERLOAD_MODELS
**Topic:** Progressive Overload Frameworks, Microcycle Progression, and Plateau Breaking
**Category:** Progression
**Evidence Base:** Rhea MR et al. (2002, PMID: 12423184); Helms ER et al. (2019); Zatsiorsky VM, Kraemer WJ. (2006, Science and Practice of Strength Training).

## Progressive Overload Systems
- **Double Progression Model (Hypertrophy Standard):** Keep the external load static while working within a rep range (e.g., 3 sets of 8-12 reps). Over successive sessions, progress repetitions. Once all 3 sets hit the top boundary (3x12), increase external load by 2.5-5% and reset reps to the bottom boundary (3x8).
- **Linear Load Progression (Novice Protocol):** Add a fixed external load increment (1.25kg - 2.5kg) every microcycle while holding sets and target reps constant. Applicable only during initial neuromuscular adaptation phases.
- **Daily Undulating Periodization (DUP - Intermediate/Advanced):** Alternate load and volume targets within the same microcycle (e.g., Session A = Strength 4x5 @ RPE 8.5; Session B = Hypertrophy 3x10 @ RPE 7.5).

## Plateau Breaking & Deload Protocol
- **Trigger:** When Estimated 1RM (e1RM) shows zero increase (\Delta e1RM <= 0) across N=3 consecutive sessions for a compound movement.
- **Action Plan:**
  1. *Deload Week:* Reduce weekly set volume by 50% and reduce intensity to 4 RIR (RPE 6).
  2. *Exercise Rotation:* Swap the stalled movement for a biomechanically similar variation (e.g., swap Flat Barbell Bench to Low-Incline Dumbbell Press).
  3. *Rep Bracket Shift:* Shift the loading stimulus (e.g., transition from 5x5 to 3x8-10).
